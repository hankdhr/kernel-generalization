# 研究设计 v0 — 2026-10-02

## 最重要的决定

把论文主问题定为：**经验如何变成模型可迁移的 kernel 优化能力？**

主张的边界是 kernel 领域的任务迁移与优化效率。即使实验成功，也不能据此断言通用智能上限提高或实现递归自我改进。只有下一轮模型更会收集有效经验、再次训练又带来持续的保留集提升，才能讨论自我改进闭环；连续多轮还需排除更大数据量和更多算力的解释。

## 模型选择

首轮主模型使用 [Qwen3-8B](https://huggingface.co/Qwen/Qwen3-8B)，从该公开检查点初始化。这里的“初始模型”不表示未经后训练的 base checkpoint。固定 non-thinking 模式，temperature=0.7、top_p=0.8、top_k=20、单次最多 8192 个生成 token。理由是先减少模式切换变量，使 8B 规模的参数更新、轨迹记录和推理预算可控；这不是最新最强模型的排名结论。

[Qwen2.5-Coder-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-Coder-7B-Instruct) 是模型家族对照。可先只做零训练基线，等主效果出现再复制训练。推理采样配置如改变，需作为单独配置报告。[Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B) 留作较新模型外部有效性验证，不能因较老主模型的改进就宣称普遍适用。

训练首选 LoRA SFT 可行性实验，rank、batch、序列长度和依赖版本由 GPU smoke test 决定。先检查 CUDA 代码正确率，若模型几乎无法得到正确代码，则先解决能力起点或实现语言难度；不要在无有效轨迹时直接启动昂贵 RL。LoRA 所需显存不能只按 8B 权重估算，还包括激活、KV、优化器和临时内存。

## Benchmark 分层

| 层次 | 内容 | 能回答什么 | 不能回答什么 |
|---|---|---|---|
| 流程预实验 | pilot-v0，6 个操作 × 3 个行数 × 3 个列数 × 2 个 stride | 测量与日志能否工作、简单条件效应能否复现 | 广泛 OOD、未知算法、SOTA |
| 受控主评测，待建 | 多族计算图；在生成样本前按规范化图结构分割 | 未见组合、shape/layout 改变的适应能力 | 完全消除预训练污染 |
| 公共对照 | 固定 revision 的 KernelBench L1/L2，后续 L3 | 公开工作间的可比趋势 | 单凭公开集证明未见任务泛化 |
| 真实案例 | FLA 的 Gated DeltaNet 候选；后续 FlashInferBench | 真实工作负载是否受益 | 单一 kernel 提速代表模型整体提升 |

pilot 的 train 为 sum/sumsq/relu-sum，dev 为 mean，test 为无权重 RMSNorm/softmax。它们共享 reduction 原语；称为**受限组合留出**，不称为计算原语族完全留出。54/18/36 是配置数，独立语义族只有 3/1/2；统计时不能当 108 个独立算法任务。

正式主评测建议涵盖逐元素融合、reduce+broadcast、layout/transpose、scan、稀疏/分段操作等，但先做算力评估。把“未见 shape 的同一 kernel 正确性”和“模型见到新任务后能否优化”分为不同评测。训练数据生成、提示检索、改进策略均不得读取最终测试轨迹。

## 主假设与判定

**H1：** 在相同模型、训练和测试预算下，成对变换及适用条件训练，比 best-code SFT 提高受控留出集 fast_1.05；同时降低达到阈值所需的尝试或时间。

**H2：** 改进至少部分保留在关闭外部经验检索的同一固定 agent 中。否则证据主要支持系统记忆的效用，不能归因于模型权重的能力变化。

**H3：** 学到的条件有预测力：在独立任务上，优化方向的预测比常用默认配置或简单特征分类器更好，尤其能识别反转和无显著收益。

先导的工程 go/no-go：测量噪声低于目标效果尺度、至少收集到一批跨条件复现的有效/无效变换、模型能产生足够正确候选。确认性门槛须在正式实验前按先导方差和预算注册；不能先看测试结果再设置。初步希望达到 fast_1.05 至少 5 个百分点的实际改善，但这只是设计目标。

## 硬件与成本

优先用户可获得的独占 H800。先采集真实型号、显存、功耗上限、驱动、CUDA、时钟/负载和 profiler 权限。截图里 vGPU 的名称不够判断物理型号和独占性。

生成与计时不能在同一 GPU 同时运行。单卡可串行卸载生成模型再测 kernel；训练也独立安排。跨卡验证是后期独立实验，不在首轮因硬件数量扩大预算。当前预算未确认，所有付费作业关闭。

## 第一轮产物

1. GPU 环境锁定及稳定性报告。
2. 初始模型的正确率、首个正确解成本、固定预算性能曲线。
3. 若干优化变换的成对证据；包含失败、无变化和效果反转。
4. 一份 go/no-go 决策，决定是否训练、换模型、缩小范围或终止假设。
